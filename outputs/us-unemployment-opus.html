Method

  • 12 US queries (2004-01 to 2026-08 monthly, all kept, non-zero share >= 0.88), individual pulls, cached in data/trends/.
  • Target modelled in first differences; benchmark set naive / drift / seasonal-naive / AR; naive won on MAE.
  • Expanding window and 36-month sliding window both evaluated; sliding windows were worse everywhere.
  • Google Trends monthly data ends 2026-08, the same month as the last BLS print, so h=0 is a one-period-ahead forecast, not a true nowcast.

Caveats

  • BLS did not publish October 2025 (shutdown); the pipeline interpolates that single month, which slightly flatters the persistence benchmark.
  • The random walk is only accurate while the labour market is calm: over the backtest its MAE is 0.10 pp when the rate is below 5% but 1.19 pp when it is above, and Google Trends did not catch the April-2020 jump either.
  • The GT gain exists only in the COVID-excluded view and only on Clark-West, which is a test of forecast encompassing, not of lower error; treat it as suggestive, not validated.
  • Recent search levels are consistent with a calm-to-cooling market (see drivers), but monthly Google Trends has no validated marginal information about the level of the rate.
